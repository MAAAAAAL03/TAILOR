# TAILOR

Spectre-calibrated system simulator for analog compute-in-memory (CIM) accelerators built from a body-driven 65-nm CMOS MAC cell.

TAILOR is a single self-contained page: open `index.html` in a browser (no install, no server).
Online version: https://maaaaaal03.github.io/TAILOR/

It explores tile sizes, peripheral organizations (DAC sharing, analog/digital partial sums, ADC per output or per tile, SRAM placement) and reconstructed state-of-the-art architectures (ISAAC/PUMA, RAELLA, TIMELY, CASCADE) on ResNet, VGG, MobileNetV2 and BERT.

Companion code of: M.-A. Laamouri et al., "Silicon-Calibrated System Exploration of Body-Driven Analog MAC Arrays," submitted to IEEE ISCAS 2027.
